# 🌄 South India Travel Guide Portal

A beautifully designed travel guide for an unforgettable **6-day road trip** through some of South India's most scenic hill stations.

## 🗺️ Route

**Bengaluru → Kodaikanal → Munnar → Bengaluru**

## ✨ Features

- 📅 Day-by-day itinerary
- 🏔️ Destination highlights
- 📸 Stunning travel photography
- 🚗 Driving distances and travel times
- 💰 Estimated trip budget
- 🍽️ Food recommendations
- 🏨 Accommodation suggestions
- 🎒 Packing checklist
- 📍 Interactive maps and travel tips
- 📱 Fully responsive design

## 🚀 Live Demo

Hosted with **GitHub Pages**.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 📖 Purpose

This project serves as a travel companion for friends and family planning a memorable road trip through the beautiful hill stations of South India.
